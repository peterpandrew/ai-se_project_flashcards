Project 1 Tripleten Flashcards

Check out this live site https://peterpandrew.github.io/ai-se_project_flashcards/ on GitHub Pages.

This project is a flash card project that lets you add decks, see decks, flip the cards and delete thm. This was created using index.html, cdd styles and javascript. In this current project, we have just added the open deck view, the confirmation modal and the responsive design. Including the new deck feature, Errors handled by displaying messages via a modal. While also showing interactions with a database via a remote API and completed documentation via JSDoc.

Check out this video https://drive.google.com/file/d/1meWUqws9A-EIJZgx1cICOGUw7MZjU9H9/view?usp=sharing, where I describe myproject and some challenges I faced while building it.
